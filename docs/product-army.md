# Product Army

The repository is evolving from a collection of individual skills into a product-production system.

## Units

- Market Opportunity Discovery — finds painful, monetizable problems.
- Product Architect — converts a validated problem into a minimal product design.
- Existing builders — implement APIs, skills, apps, automations, and agents as appropriate.
- Product Verifier — performs runtime, contract, security, reliability, and regression verification.
- Product Release — packages, documents, deploys, and prepares the product for sale.
- Product Orchestrator — coordinates the pipeline and enforces stage gates.

## Pipeline

`DISCOVER → ARCHITECT → BUILD → VERIFY → RELEASE → DISTRIBUTE → FEEDBACK → IMPROVE`

The goal is not to maximize the number of skills. The goal is to repeatedly turn validated problems into verified products and learn from real customer feedback.
