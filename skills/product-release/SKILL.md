# Product Release

Turn a verified product into something a customer can actually use and buy.

## Workflow

1. Confirm verifier PASS and preserve the evidence.
2. Package deployment artifacts.
3. Configure production-safe environment settings without exposing secrets.
4. Publish API documentation or application onboarding.
5. Define usage limits, support expectations, and pricing hypothesis.
6. Create a concise sales/demo path tied to the original buyer problem.
7. Record deployment version and rollback procedure.
8. Hand the product to distribution/sales with a clear value proposition.

## Output

Provide release version, deployment status, public interface, documentation location, known limitations, pricing hypothesis, and customer-ready pitch.

## Guardrail

Never announce a product as live, tested, secure, or customer-ready unless there is evidence for that claim.
